# Yuqing Xu Design Engineering Portfolio

Static, buildless portfolio prepared for GitHub Pages.

## Preview locally

```bash
python3 -m http.server 4173
```

Open `http://localhost:4173` from this folder.

## Structure

- `index.html` — portfolio narrative and three case studies
- `styles.css` — responsive visual system
- `app.js` — scroll reveals and interactive draggable FlowCanvas reconstruction
- `assets/` — public CodeAgent and FlowCanvas product evidence and prototype screenshots
- `Yuqing-Xu-Resume.pdf` — downloadable résumé

## Case studies

1. **CodeAgent Workbench System** — Ocean token system, MCP-exposed components, and interactive HTML prototypes (home, inbox, login, dashboard hi-fi)
2. **Farris FlowCanvas** — schema-driven agent workflow editor with an interactive draggable reconstruction and real product evidence
3. **TikTok Shop Figma-to-Code** — token-mapping workflow as a public-safe reconstruction; no internal screenshots or confidential figures

## Confidentiality

The TikTok case contains no internal screenshots. Its token map and workflow are generic reconstructions, and public copy uses ranges and qualitative outcomes rather than confidential internal figures.

## Deploy

Upload the whole folder to GitHub Pages (or any static host). No build step is required.
