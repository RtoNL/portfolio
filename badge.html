CASE 04 · CODEAGENT · INTERACTION SPEC

One red dot.
One number you can trust.

A small surface with a big job: telling developers, from the sidebar, how much work is waiting on them — without ever disagreeing with the list behind it.

Role
Spec author — rules, scenarios, iterations
Surface
Sidebar navigation · coding task list
Iterations

Format

Problem Exploration Decision Trade-offs Validation Result

1PROBLEM

A badge that counts everything stops meaning anything.

The workbench sidebar showed a count, but it mixed requirement documents, issues, and pull requests. People opened the workbench, saw a list that didn’t match the number, and learned to ignore the badge.

What actually deserves a red dot?

2EXPLORATION

Three definitions of “needs attention”.

A · Everything open

  • Never misses an item
  • Always high, so always ignored

B · Grouped by requirement

  • Mirrors how planning works
  • Doesn’t say what I should do now
  • Doesn’t match the task list
Chosen

C · Waiting on me

  • Only coding tasks that need my action
  • Matches the list exactly
  • Planning views live elsewhere

3DECISION

Three rules, written so they can be tested.

RULE 01

Count only work waiting on you.

Coding tasks that are in progress, blocked, or need changes. Documents never count.

RULE 02

Silence is a state.

With nothing waiting, the badge disappears instead of showing zero.

RULE 03

One number, one source.

The badge and the “Waiting on me” group come from the same count. No second formula.

4TRADE-OFFS

Less coverage, more trust.

WE GAVE UP

Coverage: planning documents no longer get a red dot.

→
TO GET

A number people trust, because it always matches the list. Planning has its own view.

WE GAVE UP

A reassuring zero: with nothing waiting, the badge disappears.

→
TO GET

Silence that means something, instead of a dot people learn to ignore.

5VALIDATION

Each rule became a scenario the product is checked against.

WHENTasks are in progress, blocked, or need changes

Then the badge equals their total.

WHENOnly docs or finished tasks exist

Then none of them are counted.

WHENNothing is waiting

Then no badge is shown.

WHENAny count is computed

Then badge and list use the same function.

Follow-up iterations split the list into two attention groups and moved the entry point with the new navigation — with the same rules carried through each change.

6RESULT

The number on the sidebar is the number on the page.

A developer can glance at the sidebar, see “3”, open the workbench, and find exactly three tasks waiting on them. Small, but it is the difference between a badge people trust and one they learn to ignore.
